# Security 保安

If you find a security problem with **hkalliance-archive.org**, for example a way to change its content,
or a page that loads something it shouldn't, please report it privately and **don't open a public issue**.

如發現 hkalliance-archive.org 有保安問題（例如可以更改網站內容，或網頁載入了不應載入的東西），請私下通知我們，
**不要開立公開的問題回報**。

- Email **info@hkalliance-archive.org**, or
- use GitHub's **Report a vulnerability** button under this repository's *Security* tab.

Please include the page address and what you saw. We will reply as soon as we can.
